# Typesim

An extremely simple typing simulator.  

Supports a bunch of styles, a bunch of settings (saveable)  
and is contained in a single executable!  

Making this because I have a severe typing problem, so I'll be  
using this to type a few thousand words a day in the *correct* way...  

Might add in the future:  
- Typing sounds  
- Relaxing music  

Current version: 1.0
